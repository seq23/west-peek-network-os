# Proof Layer Definitions

- Tier 1: static contracts, docs, env, no secrets, source structure.
- Tier 2: local browser/local app behavior when browser is available.
- Tier 3: postdeploy strict smoke and safety against deployed runtime.
- Tier 4: postdeploy only, Ultimate Live E2E provider + data proof.

Predeploy validation can prove Tier 4-ready but cannot prove Tier 4 success.
