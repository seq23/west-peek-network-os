# Tier 4 Report Schema

Tier 4 report fields:

- Repo
- Commit
- Deployment URL
- Run ID
- Generated timestamp
- Mode
- OAuth storage state used
- Interactive OAuth required or not
- Cloudflare/deployed runtime target
- Lane status
- Proof summary
- Warnings
- Failures
- Unproven layers
- Generated artifacts
- Final result

Passing result: `TIER 4 PASSED — ULTIMATE LIVE E2E PROVIDER + DATA PROOF`.

Blocked result: `BLOCKED — TIER 4 ULTIMATE LIVE E2E PROOF REQUIRED`.
