# Notification Setup

Notifications surface pending decisions without becoming approvals.

Recommended sender:

```text
network@joinwestpeek.com
```

V1 channels:

- In-app notifications
- Header badge
- Dashboard widget
- Daily approval digest
- Immediate email only for high-priority approvals

No one-click approvals from email. Notification links must open authenticated app pages.
