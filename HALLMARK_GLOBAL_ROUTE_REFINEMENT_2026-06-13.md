# Hallmark Global Route Refinement — 2026-06-13

## Scope

This pass applies the post-remediation Hallmark findings as a global product-design system across every West Peek Network OS route while preserving the approved black, white/cream, and orange brand.

## Global laws applied

- Primary work is visually separated from history, diagnostics, and policy.
- Every operational row exposes identity, context, state, and a clear next action.
- Similar records are differentiated by source, company, owner, method, age, or due date.
- Test/proof fixtures remain excluded from normal operator surfaces.
- Long mobile surfaces use progressive disclosure for secondary information.
- Tablet and mobile navigation use an explicit menu rather than a large permanent route block.
- Human-readable labels replace raw machine keys.
- No automatic execution, approval, payment, sending, or vendor fulfillment is implied.

## Route-specific refinements

- Dashboard: deduplicated visual queue, richer row context, actionable missing-info panels, progressive disclosure, clarified action priority, compact mobile safety notice.
- Intake Queue: record age, source, missing-field badges, identity-first review cards.
- West Peek Network: shared record hierarchy, responsive filters, lifecycle action separation.
- Touchpoints: recipient/company/method/due-date differentiation, draft preview disclosure, fulfillment state emphasis.
- Approvals: requester, assignee, risk, age, payload, and decision hierarchy.
- Notifications: unread/history separation, age and priority context, calm single-action treatment.
- Events, Add Person, Capture Studio, Thank-You, AI Review, Instructions, and Settings: shared page hierarchy, route guidance, responsive forms, action prioritization, and secondary-state treatment.

## Brand constraint

No primary palette changes were made. The system remains black/ink, white/cream, and orange, with restrained semantic status colors only.

## Proof boundary

Sandbox-safe validation passed. Real Chromium rendering and deployed visual recapture remain local/postdeploy proof.
